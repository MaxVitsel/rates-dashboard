# Дашборд курсов валют

Одна самодостаточная HTML-страница: курсы 20 валютных пар из четырёх
источников, динамика, расчётная траектория и кросс-курсы. Ни зависимостей,
ни сборки, ни внешних скриптов — только `index.html`.

## Открыть онлайн

https://maxvitsel.github.io/rates-dashboard/

На айфоне удобно добавить на домашний экран: «Поделиться» → «На экран «Домой»,
страница будет запускаться как приложение. Выбранная пара, источник, период и
тема запоминаются в браузере.

## Открыть у себя на компьютере

Скачайте репозиторий (`Code` → `Download ZIP`, распакуйте) и запустите в этой папке:

- **macOS** — двойной клик по `open-local.command`
  (в первый раз macOS может спросить подтверждение: правый клик → «Открыть»);
- **Windows** — двойной клик по `open-local.bat`.

Скрипт поднимет локальный сервер, откроет дашборд в браузере и напечатает
адрес для телефона в той же сети Wi-Fi. Остановить — закрыть окно терминала.

Вручную, если скрипт не подошёл:

```bash
python3 -m http.server 8000        # macOS / Linux
py -m http.server 8000             # Windows
npx serve -l 8000 .                # если есть Node.js
```

и открыть `http://localhost:8000/`.

**Почему нельзя просто открыть файл двойным кликом.** При открытии через
`file://` браузер запрещает странице обращаться к сайтам ЦБ и биржи (политика
CORS), и живые курсы не загрузятся: страница покажет демо-ряд и напишет, что
источник недоступен. Локальный сервер или адрес на Pages эту проблему снимают.

## Разделы

- **Динамика курса** — текущее значение, карточки MAX / MIN / AVG / CHG,
  график курса с перекрестием и подсказкой, график изменений (рост синим,
  снижение красным), таблица значений, экспорт CSV.
  Периоды: сегодня · 3 дня · неделя · месяц · квартал · год · за всё время ·
  **свой период** (две даты, плюс кнопки «последний месяц» и «с начала года»).

  Рядом с выбором пары — два необязательных списка: можно **добавить на график
  ещё одну-две пары**. Появляются легенда с изменением каждой пары за период,
  дополнительные столбцы в таблице и в CSV. Если масштабы пар сильно расходятся
  (например USD/RUB и JPY/RUB), график сам переключается на сравнение
  в процентах к началу периода — переключатель «В валюте / % к началу» рядом
  с заголовком позволяет задать это вручную.
- **Прогноз курса** — расчётная траектория на 7 / 30 / 90 дней: линейный тренд
  логарифма курса плюс диапазон 80% по волатильности дневных изменений.
  Это арифметика по загруженной истории, а не прогноз аналитиков.
- **Кросс-курс** — конвертер любой пары и матрица кросс-курсов по восьми
  основным валютам.

## Источники

| Кнопка | Откуда данные | Что отдаёт |
|---|---|---|
| **ЦБ** | `cbr-xml-daily.ru` — зеркало официальных курсов ЦБ РФ | текущий курс, архив по датам, полная таблица валют |
| **ММВБ** | `iss.moex.com`, валютный рынок CETS | последняя цена и история торгов по инструменту |
| **Форекс** | `open.er-api.com` (текущие) + `api.frankfurter.app` (история, данные ЕЦБ) | котировки мирового рынка |
| **РБК** | — | у РБК нет открытого API курсов; кнопка объясняет это и ведёт на quote.rbc.ru |

Если у источника нет нужного инструмента (например, пара не торгуется на
бирже), страница это говорит и предлагает переключить источник. Если источник
недоступен целиком, показывается демо-ряд USD/RUB с указанием причины.

## Валютные пары

К рублю: USD, EUR, CNY, GBP, JPY, CHF, TRY, KZT, BYN, AED, HKD, INR, KRW,
AMD, GEL, AZN. Кросс-курсы: EUR/USD, GBP/USD, USD/JPY, USD/CNY.

## Свои данные

Блок «Свои данные» внизу страницы принимает любой ряд в формате
`12.07 90.5045 +0.9595` (дата — `ДД.ММ`, `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`,
столбец изменения необязателен). Пока свои данные применены, источник
отключён; кнопка «Вернуть источник» возвращает живые курсы.
